# Food Best-Before Tracker Prototype

## Overview

Food Best-Before Tracker is a Python application that helps users keep track of food expiration dates and reduce food waste.

The program stores food items in a text file and allows users to check which foods have expired or will expire soon.

## Features

* Load food information from a text file
* Display expired food items
* Display food items that will expire within 7 days
* Add new food items and best-before dates
* Remove expired food items from the system
* Save updated food information to a file

## Technologies Used

* Python
* File handling
* Functions
* Lists
* Loops
* Datetime module

## How to Run 
For all users:
1. Download the project files.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

4. Enter the current date when prompted.
5. Follow the instructions on the screen.
   
For Mac users optional:
1. Download the project files.
2. Right-click `run.command`.
3. Select "Open".
4. Click "Open" when macOS asks for confirmation.

## File Format

Food data is stored in `foods.txt`.

Example:

```text
Milk,2026-06-15
Cheese,2026-06-20
Apple,2026-06-25
```
